# Library Management System

## Project Description

The Library Management System is a simple database-based application developed using Python and MySQL.

It helps manage books, library members, and book issue/return records through a simple menu-driven interface.

## Features

- Add Book
- View Books
- Search Book
- Add Member
- View Members
- Issue Book
- View Issued Books
- Return Book
- Delete Book
- Exit

## Technologies Used

- Python
- MySQL
- MySQL Connector for Python

## Database

The project uses MySQL to store:

- Book details
- Member details
- Issued book details

### Database Tables

1. `books`
2. `members`
3. `issued_books`
